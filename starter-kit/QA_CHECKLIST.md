# アルパカすく〜るラボ Starter Kit｜QA_CHECKLIST

基準：Obsidian「アルパカすく〜るラボ ゲーム制作・公開標準 第2版」

## A. 代表3画面を先に合格させる

- [ ] 体験・操作画面
- [ ] 長文結果画面
- [ ] 最終3〜4ボタン画面

この3画面が合格する前に全ステージへ横展開しない。

## B. スマホ可視領域

最低限の回帰条件：

- [ ] 390 × 560
- [ ] 390 × 650
- [ ] 390 × 760
- [ ] iPhone実機
- [ ] Safari系ブラウザUI表示中
- [ ] 画面回転後
- [ ] ピンチズーム後に操作不能にならない

確認：

- [ ] Safe Areaへ食い込まない
- [ ] 必須ボタンが下部ブラウザUIへ隠れない
- [ ] Visual Viewport同期で画面が暴れない
- [ ] 横スクロールが発生しない

## C. 操作

- [ ] タッチ対象が原則44×44 CSS px以上
- [ ] 次に押す対象が見える
- [ ] 最後の対象まで押せる
- [ ] 説明文と操作UIが重ならない
- [ ] 連打で状態が壊れない
- [ ] やり直し・戻るが機能する

## D. 日本語・ルビ

- [ ] 送り仮名が不自然に分断されない
- [ ] 1〜2文字だけの孤立行が連続しない
- [ ] 右側に大きな空白が連続しない
- [ ] ルビが親文字から離れない
- [ ] 長文に `text-wrap: pretty` を使っていない
- [ ] BudouX失敗時も本文は読める
- [ ] 文字を小さくする前に余白・行間・構造を確認した

## E. ナビ

### 1〜2ボタン
- [ ] 下部予約領域に収まる
- [ ] 本文に押し出されない

### 最終3〜4ボタン
- [ ] 2×2等で整理されている
- [ ] 本文・出典カードとの上余白がある
- [ ] ボタン間gapがある
- [ ] 下部Safe Areaとの余白がある
- [ ] sticky固定で本文に被っていない

## F. 音・動き

- [ ] 音ON/OFFがある、または音を使わない理由が明確
- [ ] 音が鳴らなくても進行可能
- [ ] 操作→動き→結果→音のタイミングが一致
- [ ] `prefers-reduced-motion` を妨げない

## G. 教材内容

- [ ] 学習目標と操作が対応している
- [ ] 史実と創作を分けている
- [ ] 未確認事項を推測で補っていない
- [ ] 出典・参考文献を実際に使った資料だけ記載
- [ ] 外部素材の権利・ライセンスを確認した

## H. Security Gate

静的教材でも最低限：

- [ ] APIキー・Token・秘密情報がない
- [ ] 個人情報・児童生徒情報を含まない
- [ ] 外部入力を追加した場合は検証・エスケープを確認
- [ ] 新規依存ライブラリの必要性・バージョンを確認
- [ ] Critical / Highの未解決問題がない
