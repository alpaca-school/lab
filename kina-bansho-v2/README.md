# 喜名番所 おしごと大作戦！3D — v0.1

開発ブランチ上の最小プロトタイプ。本番公開未承認・未検証。

## 起動
リポジトリのルートをHTTP静的サーバーで配信し、/kina-bansho-v2/ を開く。file:// ではES modulesが動作しない場合がある。
編集対象は index.html と src/game.js。現段階ではビルド不要。公開用単体HTMLへのビルドは次段階。
Three.js 0.180.0 を jsDelivr から読み込む。オフライン時は代替操作。依存の脆弱性確認・ローカル固定配布は未実施。

## 体験
旅人の到着 → 宿をタップ（または案内ボタン） → 歩行 → 感謝 → 再プレイ。
建物・人物は創作模型。史実の復元ではない。現行の kina-bansho と harly は変更しない。

## 次段階
実機QA、ハーリーとの外観比較、宿の目印、行政・道案内・交流、成長メーター、コンボ、音・時間帯、のんびり／大作戦モード。公開前に制作・公開標準第2版とSecurity Gateを確認する。
