# 旅をかなえる！旅行支援プランナー

アルパカすく〜るラボ Starter Kit を複製して作成した、旅行支援サービス要件 Ver.0.1 の教材化プロトタイプです。

## 学習目標
- 「旅行予約」と「旅行を実現可能にする支援設計」の違いを理解する
- 旅行計画、出発前、搭乗、観光、宿泊、緊急時の6場面をつなげて考える
- 旅行準備が日常生活の介助時間を圧迫し得ることに気づく
- AIが得意な整理・比較・文章作成と、人・事業者・制度が必要な支援を区別する
- 聞き取り事例の数値を制度全般の固定条件として誤解しない

## ゲーム構造
6ミッションで3択の行動を選び、最後に「確認済み／未解決」を個別旅行支援計画として振り返ります。\n\nタイトル画面と結果画面から「現地サポート検索」を開けます。行き先を入力し、義肢装具・車椅子修理、病院・救急、福祉／介護タクシー、車いす対応トイレの候補をGoogleマップで検索できます。

表示する3指標は教育用の簡易指標です。
- 確認済み：重要場面で実現条件を具体化できた数
- 未解決：追加確認が必要な重要場面
- 支援負担：選択した対応に伴う調整負担の概算ポイント（実費・介助時間ではない）

## 安全・データ
- バックエンドなし
- 認証なし
- 個人情報入力なし
- 保存なし
- 外部AI/API送信なし\n- 行き先は保存しない。検索ボタンを押したときだけ、入力した行き先と検索カテゴリをGoogleマップ検索へ渡す
- Service WorkerはStarter Kit準拠でキャッシュなし

## 教材上の注意
「公的制度で1日6時間」「完全自費で2日間8万円」等は、今回の聞き取りで示された事例です。制度全般の条件としてゲームロジックへ固定していません。

実際の旅行支援では、地域・制度・事業者・航空会社・施設・本人の支援条件について最新情報を個別確認してください。
